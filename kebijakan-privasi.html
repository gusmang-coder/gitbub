Kebijakan Privasi Perlindungan Data Pribadi

Berlaku Efektif: 1 Januari 2026
Pembaruan Terakhir: 1 September 2026
Versi: 2.4.0 (UU PDP Compliance)

1 Ruang Lingkup & Dasar Hukum

Kebijakan Privasi ini mengatur bagaimana AI & Education Global Academy Denpasar (selanjutnya disebut "Akademi", "Kami", atau "Lembaga") mengumpulkan, mengelola, memproses, menyimpan, dan melindungi Data Pribadi setiap individu yang mendaftar, mengakses situs web, menggunakan sistem Learning Management System (LMS), serta memanfaatkan fasilitas Supercomputer Virtual Lab.

Kebijakan ini disusun dengan mematuhi secara ketat ketentuan Undang-Undang Republik Indonesia Nomor 27 Tahun 2022 tentang Perlindungan Data Pribadi (UU PDP) serta standar keamanan siber internasional untuk lembaga pendidikan tinggi dan teknologi AI.

Dengan membuat akun, mengakses materi perkuliahan, atau menggunakan layanan komputasi akademi, Anda menyatakan telah membaca, memahami, dan menyetujui seluruh ketentuan dalam Kebijakan Privasi ini.

2 Data yang Kami Kumpulkan

Kami mengumpulkan data yang relevan dan dibutuhkan secara proporsional untuk keperluan akademik, sertifikasi, dan administrasi operasional kampus:

  • Informasi Identitas & Kontak: Nama lengkap beserta gelar, alamat surel (email), nomor WhatsApp/HP aktif, username akun, foto profil/avatar, dan identitas tanda pengenal (KTP/KTM/Paspor jika mendaftar beasiswa reguler).
  • Data Akademik & Pembelajaran: Program kelas yang diikuti (Online Virtual Lab atau Offline Denpasar Campus), rekam presensi, progres modul AI, submission tugas/proyek, repositori kode, dan transkrip sertifikat kelulusan.
  • Data Autentikasi: Kredensial akun terenkripsi (hash kata sandi), riwayat sesi login, token otentikasi browser (localStorage & session tokens), dan alamat IP saat mengakses portal.

3 Tujuan Pemrosesan Data Pribadi

Data pribadi yang Kami peroleh digunakan secara eksklusif untuk tujuan-tujuan berikut:

  1. Memverifikasi identitas pengguna dan memberikan akses resmi ke portal mahasiswa, portal mentor, dan portal peneliti.
  2. Menyediakan alokasi sumber daya komputasi Cloud GPU dan klaster server virtual untuk pelatihan model AI mahasiswa.
  3. Mengirimkan notifikasi penting terkait jadwal kuliah, seminar AI Summit Denpasar, hasil evaluasi hackathon, dan pembaruan sistem.
  4. Penerbitan sertifikat kompetensi berbasis digital dengan verifikasi hash kode unik internasional.
  5. Mencegah aktivitas ilegal, fraud pendaftaran, atau serangan keamanan siber terhadap infrastruktur akademi.

4 Data Telemetri & Cloud GPU Virtual Lab

Sebagai akademi kecerdasan buatan, fasilitas Virtual AI Lab kami memproses data telemetri komputasi guna memastikan stabilitas server dan mencegah penyalahgunaan:

Jenis Telemetri Deskripsi & Sumber Masa Retensi
GPU & CPU Workload Persentase utilitas komputasi saat pelatihan model neural network (PyTorch/TensorFlow). 30 Hari
Terminal Session Log Catatan command-line terminal Linux pada instance lab virtual mahasiswa. 90 Hari (audit keamanan)
API Ingestion Request Metrik konsumsi endpoint REST/GraphQL untuk evaluasi model AI. 60 Hari

5 Penyimpanan, Enkripsi & Keamanan Data

Keamanan data Anda adalah prioritas tertinggi kami. Kami menerapkan standar perlindungan berteknologi tinggi meliputi:

  • Enkripsi End-to-End: Seluruh pertukaran data melalui protokol HTTPS/TLS 1.3 dengan standar enkripsi AES-256 bit pada level database dan server.
  • Penyimpanan Akun Lokal Terproteksi: Sesi otentikasi browser pengguna disimpan pada media penyimpanan lokal (Browser LocalStorage & SessionStorage) yang diamankan dari akses skrip pihak ketiga tidak sah.
  • Zero Data Selling Guarantee: Kami TIDAK AKAN PERNAH menjual, menyewakan, atau memperdagangkan data pribadi peserta kepada pihak ketiga mana pun untuk kepentingan pemasaran komersial.

6 Hak-Hak Pemilik Data (Peserta Akademi)

Berdasarkan UU PDP No. 27 Tahun 2022, sebagai pemilik data pribadi Anda memiliki hak-hak yang dijamin hukum:

  • Hak Akses & Salinan Data: Anda berhak meminta ringkasan seluruh data profil dan catatan akademik yang tersimpan dalam sistem kami.
  • Hak Pembaruan / Koreksi: Anda dapat memperbarui informasi nama, nomor kontak, atau kata sandi Anda sewaktu-waktu melalui menu profil portal.
  • Hak Penghapusan Data (Right to be Forgotten): Setelah menyelesaikan masa studi atau memutuskan membatalkan pendaftaran, Anda berhak mengajukan permohonan penghapusan data akun Anda secara permanen.
  • Hak Portabilitas Data: Hak untuk mengunduh portofolio proyek AI dan transkrip digital dalam format terbuka (JSON/PDF).

7 Kebijakan Cookie & Sesi Login

Situs web kami menggunakan teknologi penyimpanan browser lokal (Cookies, LocalStorage, dan SessionStorage) yang berfungsi untuk:

  • Menyimpan status login akun Anda sehingga Anda tidak perlu mendaftar ulang atau memasukkan kembali kredensial setiap kali membuka halaman baru.
  • Menyimpan preferensi tampilan antarmuka dan role pengguna (Student, Mentor, atau Admin).
  • Menganalisis performa halaman web secara anonim guna mengoptimalkan kecepatan akses platform.

Anda dapat mengontrol atau menghapus data penyimpanan lokal melalui pengaturan privasi di peramban web (browser) Anda kapan saja.
