Virtual Lab GPU
10 Agustus 2026 AI Supercomputing Lab

Peluncuran Klaster Virtual Lab GPU NVIDIA H100 di Kampus Denpasar

Akademi resmi memfasilitasi mahasiswa dan peneliti dengan cluster Virtual Lab GPU NVIDIA H100 80GB untuk akselerasi praktikum machine learning & komputasi terdistribusi 24/7.

Spesifikasi & Akses Klaster Virtual Lab GPU

Kampus Denpasar kini resmi mengoperasikan 8 node NVIDIA H100 Tensor Core GPU dengan interkoneksi Quantum-2 InfiniBand 3.2 Tbps. Fasilitas Virtual Lab GPU ini memungkinkan mahasiswa kelas online maupun offline mengeksekusi model komputasi berat secara remote langsung dari browser.

Fasilitas Virtual Lab GPU:

  • Akses Terminal JupyterHub & SSH Cloud: Kompilasi script Python, PyTorch, dan CUDA 12 tanpa memerlukan laptop berspesifikasi tinggi.
  • Storage Scratch NVMe 30TB: Bandwidth I/O super cepat untuk pemrosesan dataset gigabyte.
  • Alokasi Kuota Komputasi Gratis: Setiap siswa aktif mendapatkan alokasi jam komputasi dedicated setiap pekannya.
Supercomputer Center Lt. 3, Renon Denpasar Pelajari Kelas Virtual Lab
Deep Learning
07 Agustus 2026 Deep Learning Faculty

Riset Akselerasi Deep Learning & Neural Network Multimodal untuk Edukasi

Tim peneliti akademi mempublikasikan arsitektur Deep Learning mutakhir yang mengoptimalkan transfer learning pada citra medis dan analisis konten pendidikan interaktif.

Terobosan Pemodelan Neural Deep Learning

Studi terbaru dari laboratorium Deep Learning Denpasar memadukan Convolutional Neural Networks (CNN) dan Vision Transformers (ViT) untuk menghasilkan representasi fitur berakurasi tinggi dengan efisiensi parameter 40% lebih hemat.

Manfaat & Aplikasi Riset:

  • Multi-GPU Parallel Training: Efisiensi pelatihan model skala besar menggunakan library PyTorch Distributed & DeepSpeed.
  • Edge Deep Learning Deployment: Konversi model via TensorRT dan ONNX untuk eksekusi real-time pada robotika dan IoT.
  • Open Source Codebase: Kode riset dan bobot model pre-trained dibagikan secara terbuka di repositori akademi.

LLM & NLP
05 Agustus 2026 NLP Research Lab

Pengembangan Model Large Language Model (LLM) & NLP Bahasa Daerah Nusantara

Inovasi model AI pemrosesan bahasa alami (NLP) berkonteks multibahasa Nusantara untuk memperkuat sistem pembelajaran cerdas dan asisten virtual lokal.

Arsitektur LLM & NLP Multibahasa

Riset NLP berfokus pada teknik Retrieval-Augmented Generation (RAG) dan fine-tuning arsitektur Transformer 7B/13B parameter untuk mengenali ragam tata bahasa dan dialek lokal secara presisi.

Keunggulan Model:

  • Context Window 128k Tokens: Mampu membaca naskah riset dan modul pembelajaran panjang dalam hitungan detik.
  • Low-Latency Inference: Teroptimasi menggunakan framework vLLM pada klaster GPU NVIDIA H100 kampus.
  • Penerapan AI Tutor: Diintegrasikan langsung sebagai tutor pendamping otomatis bagi seluruh mahasiswa akademi.
Model Open-Weights & API Tersedia Ikuti Kelas Gen AI & LLM
Workshop
18 Agustus 2026 09.00 - 15.00 WITA

Workshop National Prompt Engineering for Educator 2026

Pelatihan intensif 1 hari pembuatan asisten pengajar otomatis menggunakan API OpenAI & Claude untuk ribuan pengajar dan dosen di Indonesia.

Kurikulum Hands-on Workshop

Didesain untuk guru, dosen, dan praktisi pendidikan yang ingin mengintegrasikan generative AI secara praktis dalam penyusunan RPP, modul ajar interaktif, dan tutor virtual 24 jam untuk siswa.

Materi yang Dipelajari:

  • Advanced Prompt Frameworks: Chain-of-Thought, Few-Shot Prompting, dan System Prompt Optimization.
  • Membangun AI Teaching Assistant Tanpa Coding menggunakan Custom GPTs & Claude Artifacts.
  • Sertifikat Resmi 32 JP yang diakui kementerian dan lembaga pendidikan nasional.
